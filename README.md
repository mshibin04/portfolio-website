# My Portfolio Website

Hey! 👋

This is my personal portfolio website that I built while learning **HTML and CSS**.

I wanted to make something of my own instead of just following tutorials, so I decided to build a simple portfolio where I can introduce myself and eventually showcase the projects I make.

I'm still learning, so this website is definitely going to change over time.

## About the Project

The main idea was pretty simple — make a website for myself and use it as a way to practice what I've been learning.

I've already worked with HTML and CSS for a while through class projects and other practice, so I wasn't starting completely from zero. This project gave me a chance to use those skills in something personal.

I kept the technologies simple for now and focused mainly on getting the structure and design right.

## Technologies Used

* HTML
* CSS
* Git & GitHub
* Vercel

HTML handles the structure of the website, while CSS is used for the design, layout, positioning, fonts, spacing, and other visual stuff.

I used GitHub to manage the project and Vercel to deploy it.

## Project Files

`index.html` is the main page of the website.

`style.css` contains the styling and layout.

`main.png` is an image used in the website.

And `README.md` is, well... this. 😭

## About AI

I didn't use AI to generate the website.

I did try using AI for one small thing, though. I was trying to align the GitHub icon exactly where I wanted it, so I asked AI for a solution. It didn't work properly with my website, so I removed that part instead of keeping code that wasn't working.

The rest of the website was written and worked on by me.

I've also been working with HTML and CSS for a while through school projects and my own practice, so if some of the code looks better than you'd expect, that's probably because I've gotten more comfortable with it over time. 😭

I've learned by actually making things, watching tutorials, doing class projects, experimenting, and fixing my own mistakes.
